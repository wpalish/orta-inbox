# Происхождение

Оригинальное ядро WorkStore/HTTP, базовые CSS/index/start и лицензия переиспользованы из собственного QorStock (wpalish,6b394713547d102263b25e8a1a40416e6bf5514e). Разрешение владельца на собственный код действует. module.js, workflow.test.js и интерфейс очереди/версии написаны для OrtaInbox. HTTP дополнен чтением списка аккаунтов и проверкой существующего ответственного при записи обращения. Общий код не выдаётся за уникальную библиотеку; предметный механизм отличается.

Crisp использован как публичный референс категории, без исходников, изображений, копирования бренда или материалов. Браузерные записи и примеры синтетические. В Git нет баз, паролей, сессий или клиентских данных.
